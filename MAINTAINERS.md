# Maintainers

| Maintainer | GitHub | Area |
|------------|--------|------|
| kingchenc  | [@kingchenc](https://github.com/kingchenc) | Lead — core, renderers, bindings, releases |

Maintainers are responsible for reviewing pull requests, keeping CI green,
cutting releases and setting direction. See [GOVERNANCE.md](GOVERNANCE.md).

## Contacting the maintainers

- General questions and support: see [`SUPPORT.md`](SUPPORT.md).
- Bug reports and feature requests: open an issue using the
  [issue templates](.github/ISSUE_TEMPLATE).
- Anything else that should stay private, and every security report: email
  **support@wickra.org** and follow [`SECURITY.md`](SECURITY.md). Do **not**
  open a public issue for a vulnerability.

## Continuity

This is a single-maintainer project, so what happens if that maintainer stops
is written down rather than assumed: see
[Continuity and succession](GOVERNANCE.md#continuity-and-succession).
