# Build and test tooling for the Python binding's CI job.
#
# Pinned rather than installed unversioned, so a CI run is reproducible and a
# tool release cannot change what the job does without a commit saying so.
# It lives here rather than inline in the workflow because dependabot watches
# pip in this directory and does not read workflow files, so an inline pin would
# quietly rot while looking maintained.
maturin==1.15.0
# pytest is split by marker because no single version covers the matrix safely.
# PYSEC-2026-1845 (CVE-2025-71176, vulnerable tmpdir handling) is fixed in 9.0.3,
# and pytest 9 requires Python >= 3.10 -- while the matrix floor is 3.9, the abi3
# floor the wheel is built against. The 8.x line ends at 8.4.2 and carries no
# backport, so 3.9 has no patched pytest at all and gets the newest that runs
# there; every other cell gets the fix.
#
# Collapse this back to one pin once the matrix floor moves off 3.9.
pytest==8.4.2; python_version < "3.10"
pytest==9.1.1; python_version >= "3.10"
