Wickra Terminal in the browser

The whole core compiled to WebAssembly: it folds the feed, keeps the state and produces the frames, entirely client-side. Nothing here is a mock — this is the same core the native TUI runs, driven through the same three calls.

The full Web renderer lives in web/. This page is the smaller thing: the shortest program that drives the core from a browser, so a reader can see the shape of it without a build tool.
